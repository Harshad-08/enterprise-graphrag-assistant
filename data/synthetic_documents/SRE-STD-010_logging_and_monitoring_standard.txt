# 1. Scope
This standard applies to all services running on production systems.

# 2. Log Collection
All services must send application logs to the central logging platform.
Application logs are retained for 90 days and then deleted.
Logs must not contain passwords, access tokens or payment card numbers.

# 3. Alerting
Every production service must define availability alerts before launch.
