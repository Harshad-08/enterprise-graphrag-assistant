# 1. Scope
This standard governs human access to every production database. This standard implements the Information Security Policy for database workloads.

# 2. Access Requirements
Access to a production database requires an approved access request in ServiceDesk.
Multi-factor authentication is required for every production database session.
Engineers must connect to a production database only through the Bastion Host.
Direct connections from laptops to a production database are prohibited.

# 3. Privileges and Sessions
Production database accounts are read-only by default.
Write access requires an approved change ticket and expires after 4 hours.
All production database sessions are recorded and retained for audit.
Production database access is reviewed quarterly by Information Security.
