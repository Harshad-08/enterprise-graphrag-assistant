# 1. Scope
This standard governs authentication for every service exposed through the Public API Gateway. This standard implements the credential requirements of the Information Security Policy.

# 2. Authentication Requirements
All API clients must authenticate with OAuth 2.0 using the client credentials flow.
Access tokens expire after 60 minutes.
Static API keys are prohibited for new integrations.
Client secrets must be rotated every 90 days.
Partner integrations must use mutual TLS in addition to OAuth 2.0.

# 3. Rate Limiting
Each client is limited to 600 requests per minute by default.
